# アトランチスの謎｜全100面ワープルート図

ファミコン用ゲーム『アトランチスの謎』のワープルートを確認するための、非公式・個人制作のHTMLマップです。

**[マップを開く (GitHub Pages)](https://MASA-6cha.github.io/atlantis-no-nazo-warp-map/)**

## 機能

- 1面を左上に配置した全100面＋裏FINALのワープ接続図
- マップ枠内での上下左右ドラッグ移動、拡大・縮小
- ステージの選択、行き先・流入元の確認、ワープ種類別フィルター
- 出発面・目的面を指定した最短ルート検索（移動回数ベース／一部条件付きルートを考慮）
- ROMから生成したステージ開始画面の表示
- ROM由来のアイテムドット絵、効果、出現する面の一覧
- オフライン動作（必要な画像はHTML内に埋め込み済み）

## 使い方

`index.html` をブラウザで直接開いてください。外部ライブラリやROMファイルの読み込みは不要です。

## GitHub Pagesで公開する場合

1. GitHubでリポジトリ `atlantis-no-nazo-warp-map` を作成します。
2. このフォルダの **`index.html` と `README.md` と `.nojekyll`** をリポジトリのルートにアップロードします。**ZIPファイルをそのままアップロードしてもページにはなりません。**
3. GitHubのリポジトリの **Settings → Pages** から **Deploy from a branch / main / (root)** を設定します。
4. 公開される場合の予定URLは `https://MASA-6cha.github.io/atlantis-no-nazo-warp-map/` です。実際のURLはリポジトリ名とGitHub Pages設定によります。

## データの注意点

- ワープ図と実機動作の完全一致を保証するものではありません。ROM内の扉データとの照合結果および条件付き経路の注意事項はアプリ内に記載しています。
- 一部のアイテム効果や取得条件は攻略資料に依存しており、未確認事項が残っています。
- 最短ルートは最少面移動回数の探索であり、プレイ時間の最短ルートを保証するものではありません。
